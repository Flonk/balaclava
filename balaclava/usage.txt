Usage: balaclava [OPTIONS]

  -h, --help                        Show this help

PipeWire:
  --sink [TARGET]                   Capture from a sink (default: @DEFAULT_SINK@)
  --source [TARGET]                 Capture from a source (default: @DEFAULT_SOURCE@)
  --sink2 [TARGET]                  Secondary sink (rendered behind primary)
  --source2 [TARGET]                Secondary source (rendered behind primary)
  --sample-rate N                   Sample rate in Hz (default: 48000)

Spectrum:
  --frame-size N                    FFT frame size (default: 2048)
  --hop-size N                      FFT hop size (default: 512)
  --min-freq N                      Min frequency in Hz (default: 20)
  --max-freq N                      Max frequency in Hz (default: 20000)
  --dynamic-falloff N               Peak hold half-life in ms (default: 1000)
  --dynamic-rise N                  Rise half-life in ms (default: 50)
  --auto-gain-floor N               Auto gain floor (default: 0.01)

Display:
  --render oneline|fullscreen|ascii Render mode (default: fullscreen)
  --bars N                          Number of bars (default: auto)
  --bar-width N                     Bar width in chars (default: auto)
  --gap N                           Gap between bars in chars (default: auto)
  --headroom N                      Max bar height 0-1 (default: 0.8)
  --pad-top N                       Top padding in rows (default: 1)
  --pad-left N                      Left padding in cols (default: 1)
  --pad-bottom N                    Bottom padding in rows (default: 1)
  --pad-right N                     Right padding in cols (default: 1)
  --orientation MODE                Orientation: auto, vertical, horizontal (default: auto)
  --alignment POS                   Bar alignment: auto, start, middle, end (default: auto)
  --alignment2 POS                  Secondary bar alignment (default: auto)
  --baseline on|off|auto            Show baseline at bar origin (default: auto)
  --baseline2 on|off|auto           Secondary baseline (default: auto)

Colors:
  Colors accept OKLCH "L C H" or hex "#rrggbb". OKLCH values are lightness
  (0-1), chroma (0-0.4), and hue (0-360). Gradients interpolate in OKLCH.

  Examples:   --color-hi "0.75 0.15 145"   bright green in OKLCH
              --color-hi "#4ade80"         same green in hex

  --bg-color COLOR                  Background color (default: 0 0 0)

  --color-lo COLOR                  Gradient low color (default: 0.3 0 0)
  --color-hi COLOR                  Gradient high color (default: 0.7 0 0)
  --beat-color COLOR                Beat pulse color (default: 0.88 0.1 70)

  --color-lo2 COLOR                 Secondary gradient low (default: 0.15 0.02 280)
  --color-hi2 COLOR                 Secondary gradient high (default: 0.28 0.03 280)

MPRIS:
  --mpris-mode MODE                 off, text, full (default: text)
  --mpris-color COLOR               MPRIS text color (default: 0.5 0 0)
  --mpris-ui-color COLOR|auto       Button color (default: auto = bar color)
  --mpris-bg-color COLOR|auto       Widget background color (default: auto = bg-color)
  --mpris-bar-color COLOR           Progress bar color (default: 0.4 0 0)
  --mpris-width N|auto              Widget width (default: auto = min(46, 2/3 display))
  --mpris-overflow MODE             ellipsis, marquee, pingpong, auto (default: auto)
  --mpris-text-align A              left, center, right, auto (default: auto)
  --mpris-padding-horizontal N      Horizontal padding (default: 0)
  --mpris-padding-vertical N        Vertical padding (default: 0)
  --mpris-position POS              Position: auto, topleft, top, topright, right,
                                    bottomright, bottom, bottomleft, left, center
                                    (default: auto)
  --hotkeys on|off                  Keyboard shortcuts (default: on)
  --volume-scroll on|off            Ctrl+scroll volume control (default: on)

Effects:
  --smoothing N                     Smoothing alpha 0-1 (default: 0.65)
  --gravity N                       Gravity decay 0-1 (default: 0.93)
  --gravity-rise N                  Rise inertia 0-1 (default: 0.0)
  --gravity-power N                 Gravity easing exponent (default: 6.0)
  --noise-reduction N               Noise reduction 0-1 (default: 1.0)
  --eq-bass N                       Bass gain at min freq (default: 3.0)
  --eq-mid N                        Mid gain at center (default: 0.8)
  --eq-treble N                     Treble gain at max freq (default: 1.8)
  --contrast N                      Gamma curve exponent (default: 1.5)
  --monstercat-falloff N            Monstercat falloff factor (default: 1.5)
  --no-monstercat                   Disable monstercat smoothing

Beat detection:
  --beat-detection on|off           Enable/disable beat detection (default: on)
  --beat-detection2 on|off          Beat detection for secondary (default: off)

  --beat-decay N                    Beat intensity decay 0-1 (default: 0.9)
  --beat-gamma N                    Beat intensity gamma (default: 1.6)
  --beat-floor N                    Max beat floor for clean signals (default: 0.6)
